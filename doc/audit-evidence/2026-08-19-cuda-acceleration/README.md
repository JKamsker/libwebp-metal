# CUDA acceleration audit evidence — 2026-08-19

This directory is a verbatim extraction of
`cuda_accel_audit_bundle(1).zip`, supplied for the CUDA acceleration audit.
It is retained so the original findings, host proofs, source assertions,
release-archive manifests, build logs, and toolchain record can be checked
independently of the remediation.

The current-tree disposition of every finding is recorded in
[`../../cuda-acceleration-audit-remediation-20260819.md`](../../cuda-acceleration-audit-remediation-20260819.md).

`SHA256SUMS` covers every original file from the supplied archive. The README
and checksum manifest are repository metadata and therefore are not listed in
that manifest.

Verify the preserved files from this directory with:

```sh
sha256sum -c SHA256SUMS
```
