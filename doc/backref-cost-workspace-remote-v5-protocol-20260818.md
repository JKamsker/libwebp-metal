# Frozen remote v5 protocol

The sole later timing authority is exactly one invocation of
`execute_backref_cost_workspace_remote_v5.py run` against `pandocs-agent` with
the exact clean handoff commit and `WEBP_BENCHMARK_SESSION=exclusive`.
Repository-context bundle verification, detached commit/tree, clean status,
source hashes, canonical v5 path guard, host/power/process/resource admission,
one nonblocking lease, serial children, and independent cleanup are conjunctive.

Before the lease and any timing, the operator admits the frozen explicit
makefile toolchain and records executable paths/canonical targets, hashes,
versions, effective compiler/SDK/developer directory, environment, compiler/SDK
probe, and exact build commands. Baseline and candidate are separate clean
source clones. Both build static `cwebp`, `dwebp`, libwebp, and sharpyuv via the
same make command; the v5 build flag is exactly 0 then 1, and the default runner
is linked from default archives. CMake, Homebrew/MacPorts, ambient tool lookup,
network downloads, host/service/power changes, CUDA, and recorders are forbidden.

The frozen question and matrix are unchanged: 13 correctness rows by methods 4
and 6 give 26 cells; medium photo/graphic/texture tune precedes large
photo/graphic/texture holdout; method 4 precedes 6; cold precedes warm. Cold has
11 alternating process pairs, zero warmups, one retained encode. Warm has six
alternating pairs, two discarded and nine retained. Totals are 408 command
processes, 264 cold samples, 288 warmups, 1,296 warm samples, 1,560 measured,
780 measured per variant, 24 evaluation cells, and 12 required holdout cells.

Timing is runner-local `mach_continuous_time` around `WebPEncode` only. A cell
uses the median of paired candidate/baseline process medians and nearest-rank
raw p95 ratio. Tune is descriptive. Every holdout cell must have paired median
ratio <= 0.99 and p95 ratio <= 1.01. Promotion additionally requires every
ancestry, identity, default omission, predecessor isolation, bitstream,
decoded-pixel, repeat, fallback, immutable-input, toolchain, host, power,
process, resource, lease/release, archive/index/hash/extraction, and exact
cleanup criterion. No result may be pooled with v4's zero-sample refusal.

Every controlled operator exit has a complete remote artifact index, including
toolchain/build/preflight refusal. The driver independently fetches and hashes
the lease record, then builds/transfers/inventories/extracts the indexed archive,
then removes only the exact validated child and independently returns absence
proof. Extractor rejection is all-or-nothing and quarantined. No rerun, edit,
tune, local timed fallback, threshold change, or executor decision is allowed.
